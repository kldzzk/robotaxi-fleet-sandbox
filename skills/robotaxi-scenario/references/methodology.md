# 方法论速查

完整版见仓库 `docs/methodology.md`。

## 公式

```
被替代订单      = 城市日均订单 × 情景压力 × 净替代系数
需新增 Robotaxi = ceil(被替代订单 ÷ Robotaxi 单车日均订单)
传统车队剩余    = (日均订单 − 被替代订单) ÷ 传统单车日均订单
传统车队降幅    = (原车队 − 剩余车队) ÷ 原车队
```

## 变量

| 变量 | 含义 |
|---|---|
| `base_daily_orders` | 城市日均出行订单 |
| `traditional_fleet` | 传统车队规模（日均活跃运力） |
| `traditional_daily_orders_per_vehicle` | 传统车单车日均订单 |
| `robotaxi_daily_orders_per_vehicle` | Robotaxi 单车日均订单 |
| `pressure` | 情景订单压力（0–1） |
| `net_substitution_ratio` | 净替代系数（默认 1.0） |

## 口径

- `paper_baseline` 用 942,000 单、47,100 辆、单车 20 单，复现论文 5%/10%/20% →
  2,355/4,710/9,420 辆。
- 0.27 是论文对 Liao 等（2027）需求模型的校准比例，默认视为已内化进情景压力；
  需要“仅按 0.27 折算”的视图时用 `--net-ratio 0.27`。
- 广州/成都/杭州订单由「单车日均订单 × 日均活跃车辆」派生；武汉/绵阳为直接口径。

## 局限

- 线性替代，未考虑低价诱导的新增出行。
- 单车产能固定，未内生拥堵、空驶率、运营时段与充电。
- 政策许可、事故责任、充电与维护成本未建模。
- 结果是情景测算，不是预测，也不构成投资建议。
